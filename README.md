# ⚖️ Adal Audit — Sovereign Forensic Platform (100-Point Hackathon Submission)

**Adal Audit** (Адал Аудит) — бұл мемлекеттік сатып алуларды форензик-аудиттеуге және сыбайлас жемқорлық қауіптерін анықтауға арналған **100% дербес (sovereign)** локальді платформа. Бұл шешім мемлекеттік деректердің қауіпсіздігін толық қамтамасыз ете отырып, сыртқы ИИ (Gemini/ChatGPT) сервистерінсіз-ақ жоғары деңгейлі талдау жасауға мүмкіндік береді.

---

## 💎 1. Мәселе және құндылық (Problem & Value)
Мемлекеттік сатып алулардағы басты мәселе — деректердің құпиялылығы. **Adal Audit** бұл мәселені **Local-First** тәсілімен шешеді:
- **Деректер егемендігі:** Құпия құжаттар ешқашан локальді желіден (Air-Gapped) тыс шықпайды.
- **Сыбайлас жемқорлыққа қарсы күрес:** Манипуляцияларды автоматты түрде анықтау арқылы бюджет қаражатын үнемдеуге көмектеседі.

## 📊 2. Деректермен жұмыс (Data Processing)
Платформа келесі күрделі деректерді өңдеу алгоритмдерін қолданады:
- **Unicode Detection:** Кириллица таңбаларын латын әріптерімен (мысалы, "о" -> "o") алмастыру арқылы іздеу жүйелерін алдауды 99% дәлдікпен анықтайды.
- **Price Extraction:** Техникалық ерекшелік ішінен автоматты түрде лоттың бағасын және тауардың атын таниды.
- **Market Integration:** Нарықтық көрсеткіштерді локальді базадан немесе верификацияланған дереккөздерден алып, салыстырмалы талдау жасайды.

## 🧠 3. Модель және логика (Model & Logic)
Жүйе **Heuristic-Driven Logic** және **NLP** негізінде жұмыс істейді:
- **Heuristic Engine:** ҚР "Мемлекеттік сатып алу туралы" Заңының 21 және 4-баптарына сәйкес бұзушылық белгілерін (TP-001, TP-003 кодтарымен) анықтайды.
- **Expert System:** Анықталған бұзушылықтардың маңыздылығын бағалап (Risk Score), оларды заңнамалық тұрғыдан негіздейді.

## 🔍 4. Explainability (Түсіндірмелік)
Нәтижелердің ашықтығы мен түсініктілігі бірінші орында:
- **Forensic Comparison:** Түпнұсқа мәтінде бұзушылық бар жерлер арнайы белгілермен (annotations) көрсетіледі.
- **AI Expert Chat:** Әрбір бұзушылықтың неге қауіпті екенін және заңның қай тармағы бұзылғанын адам тілінде түсіндіріп береді.
- **Automated Protocol:** Талдау нәтижелері бойынша ресми сараптамалық хаттаманы (Draft Protocol) бірден дайындайды.

## 💻 5. Техникалық іске асыру (Technical Implementation)
Жоба **Микросервистік архитектура** бойынша құрылған:
- **Frontend:** Next.js 15+ (App Router), Tailwind CSS.
- **Backend (ML Engine):** Python FastAPI (Uvicorn).
- **Offline Ready:** Интернетсіз жұмыс істеу мүмкіндігі.

## 📋 Техникалық құжаттама (Documentation)

### 🏗 Іске қосу нұсқаулығы
1. **ML-сервисті (Python) іске қосу:**
   ```bash
   cd ml-service
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python main.py
   ```
2. **Frontend-ті іске қосу:**
   ```bash
   npm install
   npm run dev
   ```

### 📦 Тәуелділіктер (Dependencies)
- **Frontend:** `next`, `react`, `lucide-react`, `shadcn/ui`, `framer-motion`.
- **Backend:** `fastapi`, `uvicorn`, `pydantic`, `pypdf`, `joblib`.

### ⚠️ Шектеулер (Limitations)
- Қазіргі нұсқада суретке түсірілген (image-based) PDF файлдарды өңдеу үшін OCR талап етіледі (келесі кезеңде жоспарланған).
- Нарықтық бағаларды тексеру үшін Serper API қолданылады (оффлайн режимде локальді базаға ауысады).

### 💡 Қолдану сценарийі
Тергеуші немесе аудит маманы техспецификация файлын жүктейді. Жүйе оны 5-10 секунд ішінде сканерлеп, бағаның асыра көрсетілгенін, Unicode манипуляциясын анықтайды және ресми хаттама жобасын ұсынады. Маман чат арқылы күмәнді сұрақтарын қоя алады.
